# Monsoon Flow — Game Specification Package

This repository contains the documentation and Cursor instructions required to **implement** the game; it is not yet the finished game.

Place the contents in the **root of your Cursor project**. Read `docs/00_START_HERE.md`. Cursor Agent can then be told:

> Read AGENTS.md and all documentation in docs/. Implement Monsoon Flow end-to-end, following docs/10_IMPLEMENTATION_ROADMAP.md, and run the checks in docs/11_ACCEPTANCE_TESTS.md. Proceed autonomously, preferring a fully working vertical slice before optional features.

`.cursor/rules/monsoon-flow.mdc` is the always-applied project rule; `.cursor/skills/*/SKILL.md` provide focused local skill playbooks. No paid services are required to build or deploy the planned frontend-only MVP.
